# Phrase_processor_psp_2023
Proyecto en Java para PSP centrado en la gestión de procesos. Implementa ProcesarFrases para ‘cantar’ un texto con una sola vocal utilizando dos procesos: ReemplazarVocales y Cantar. Incluye pruebas unitarias y especificaciones detalladas para guiar el desarrollo, haciendo énfasis en la creación de procesos, manejo de argumentos y códigos de error.
